❓ Help
How to use Sarcasm Sense

Getting Started

  • Type any sentence in the Dashboard input box and click Predict.
  • Or tap the 🎙️ mic button and speak aloud — your voice is transcribed automatically.
  • The result shows the detected language, sentiment, sarcasm verdict, and a confidence score.
  • Click 🔊 Speak Result to have the verdict read aloud using your browser's text-to-speech engine.

Pages Explained

  • Language Mix — charts showing which languages have been detected across all your analyses.
  • Sentiment — positive / negative / neutral breakdown and how sentiment correlates with sarcasm.
  • History — searchable log of every prediction. Use the search box to filter by text or language.
  • Alerts — auto-triggered when a prediction is sarcastic with confidence > 80%.
  • Model Info — LSTM architecture, training parameters, and supported languages.

Speech-to-Text Tips

  • Works best in Google Chrome or Microsoft Edge.
  • Allow microphone access when the browser prompts you.
  • For Hindi or Marathi, try speaking naturally — the transcript may include Romanized words.
  • You can edit the transcript in the text box before clicking Predict.
🔒 Privacy
How your data is handled

Data Storage

All predictions are saved locally to analysis_history.json on the server running this app. No data is sent to any external service or third party.

Speech Input

When you use the microphone button, your audio is processed by your browser's built-in Web Speech API (provided by Google in Chrome). Audio is not stored by this application — only the resulting text transcript is used for prediction.

Profile Information

Profile data (name, role, GitHub) is saved only in your browser's session memory and is never sent to the server. It resets when you close the tab.

Text-to-Speech Output

The Speak Result feature uses the browser's built-in speechSynthesis API and runs entirely locally on your device. No audio leaves your browser.
