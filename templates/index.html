❓ Help
How to use Sarcasm Sense

Getting Started

  • Type any sentence in Dashboard and click Predict.
  • Tap 🎙️ to speak instead of typing — transcript fills the box automatically.
  • Use 🌐 Translator to translate text before or after analysis across 20+ languages.
  • Click 🔊 Speak to have the verdict read aloud via text-to-speech.
  • After translation, tap "Analyze for Sarcasm" to send the translated text to the predictor.

Translator Guide

  • Select source and target languages, or choose Auto-detect for the source.
  • Use the ⇄ swap button to reverse the language pair instantly.
  • Try the Quick Phrases chips to explore sarcasm across languages.
  • Translation history is kept in-session for quick reference.
  • Powered by the MyMemory free API — no API key required.

Mobile Tips

  • Use the bottom navigation bar to switch between Dashboard, Translator, History, Alerts, and More.
  • Tap ☰ in the top-left to open the full sidebar on mobile.
  • Speech-to-text works in Chrome for Android and Safari for iOS.
  • Add to your home screen for an app-like experience (Share → Add to Home Screen).

History & Export

  • Use the search box and filter chips to narrow results by verdict, language, or text.
  • Click Export CSV to download your full prediction history as a spreadsheet.
🔒 Privacy
How your data is handled

Prediction Data

All predictions are saved to analysis_history.json on the local server. No prediction data is sent to external services.

Translation

Translations use the MyMemory public API. Text you translate is sent to MyMemory's servers. Do not translate sensitive or personal information. See MyMemory's terms.

Speech Input

Microphone input is processed by your browser's Web Speech API (Google in Chrome). Only the resulting text transcript is used — no audio is stored by this app.

Profile & Settings

Profile data and settings are stored in your browser's localStorage and never sent to the server. They persist across sessions on the same device.
