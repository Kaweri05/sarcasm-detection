# ============================================================
#   KEY DATA FLOW
# ============================================================
#
#   User Input (text / voice)
#       ↓
#   templates/index.html  (frontend)
#       ↓  POST /predict
#   server.py             (Flask backend)
#       ↓
#   Language Detection    (word-list heuristic)
#   Sentiment Analysis    (TextBlob)
#   Sarcasm Prediction    (heuristic / LSTM model)
#       ↓
#   JSON Response → frontend renders result + chart
#       ↓
#   backend/analysis_history.json  (persisted log)
#
# ============================================================
#   TECH STACK
# ============================================================
#
#   Language      : Python 3.10
#   Backend       : Flask 3.1.3
#   ML Framework  : TensorFlow-CPU 2.15.0 / Keras
#   Model         : LSTM (Long Short-Term Memory)
#   NLP           : NLTK, TextBlob
#   Translation   : MyMemory Free API (22+ languages)
#   Frontend      : HTML5, CSS3, Vanilla JS, Plotly.js
#   Speech I/O    : Web Speech API (browser-native)
#   Deployment    : Hugging Face Spaces (Docker)
#   Dataset       : Sarcasm Headlines Dataset (Kaggle)
