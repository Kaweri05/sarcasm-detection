# Node & Frontend Dependency Information
# Sentify — Multilingual Sarcasm Detection Dashboard
# =====================================================
# This project is a Python/Flask backend application.
# It does NOT use Node.js, npm, or any JavaScript build tools.
# The frontend is plain HTML/CSS/JS served by Flask (Jinja2 templates).
#
# WHY THIS FILE EXISTS:
# Platforms like Netlify/Vercel look for Node.js projects.
# Sentify is NOT a Node.js project — use Hugging Face or Render instead.
#
# COMPATIBLE DEPLOYMENT PLATFORMS:
# ✅ Hugging Face Spaces (Docker) — https://huggingface.co/spaces
# ✅ Render                       — https://render.com
# ✅ Railway                      — https://railway.app
# ✅ Kaggle Notebooks             — https://kaggle.com
#
# INCOMPATIBLE PLATFORMS (Python/TensorFlow not supported):
# ❌ Netlify  — static sites only
# ❌ Vercel   — no TensorFlow wheels for Python 3.12
#
# PYTHON VERSION REQUIRED: 3.10.x
# FRAMEWORK: Flask 3.1.3
# ML FRAMEWORK: TensorFlow-CPU 2.15.0
